# Spotify Music Analytics Dashboard

An interactive data analytics web application that fetches, processes, and visualizes music streaming data using Python and Streamlit.

## 🚀 Features
- **Interactive UI:** Built using Streamlit for seamless data presentation.
- **Data Visualizations:** Dynamic charts representing music insights.
- **API Integration:** Processes structured JSON data structures.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
- **Libraries:** Pandas, Plotly/Matplotlib (sesuaikan dengan library visualisasi yang lo pakai)

## 💡 Learning Outcomes
This project was developed as a post-graduation independent study to master the software development lifecycle, third-party API integration, and hands-on data analysis protocols.
